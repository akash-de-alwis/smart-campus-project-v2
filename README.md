# Smart Campus Project

A full-stack smart campus application with a Spring Boot backend and a React/Vite frontend for managing bookings, resources, tickets, users, and notifications.

## Project Structure

- backend: Spring Boot API and business logic
- frontend: React/Vite UI
- docs: project guidance and access-control notes

## Tech Stack

- Backend: Java, Spring Boot, Spring Security, MongoDB
- Frontend: React, Vite, Tailwind CSS, Zustand

## Getting Started

### Backend

```bash
cd smart-campus-backend
./mvnw spring-boot:run
```

### Frontend

```bash
cd smart-campus-frontend
npm install
npm run dev
```

## Notes

- Configure environment variables and OAuth settings before running the app.
- The repository includes a basic gitignore setup for build artifacts and local environment files.
